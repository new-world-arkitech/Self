Read it. Prove it. Become it.

Self. turns the guides, protocols and documents you already own into verified skill, and shows your progress on a 3D avatar that changes as you do.

Get started See the five domains

Raise a domain and watch the matching layer appear.

One loop, five steps

Nothing counts until you show you can do it.

  1. DropAdd a PDF, Word, Markdown or text file.
  2. ExtractSelf. pulls out concepts and milestones.
  3. VerifyPass a quiz or complete a real-world task.
  4. EvolveXP is logged and your avatar changes.
  5. MeasureTrack grit, retention and velocity over time.

Run it on your machine

You need Python 3.10+ and Node.js 18+. Everything runs locally.

1. Configure

cp .env.example .env

2. Ingest your documents

python src/engine/universal_ingestor.py

3. Launch the dashboard

python src/engine/server.py
# open http://127.0.0.1:8000

Manage missions from the command line

python src/engine/task_manager.py add \
  "Review toxic plant red flags" \
  Self.knowledge 50

python src/engine/task_manager.py list
python src/engine/task_manager.py complete <task_id>
python src/engine/task_manager.py stats

Your data stays yours

Local-first

Documents, state and journal logs never leave your machine. The career, credit and legal folders, and all .env files, are gitignored so personal and financial records are never committed.
